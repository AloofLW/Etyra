# Etyra 项目总览

## 产品目标

完整目标、用户问题、非目标和成功标准见 `docs/PRODUCT_GOAL.md`。本文件只保留项目范围和版本总览。

## 项目定位

Etyra 通过词根、词缀和构词关系帮助用户理解并记忆英语单词。学习主线是“认识构词成分 → 学习关联单词 → 主动回忆 → 后续复习”，体验参考扇贝单词的节奏，但不复制其实现或内容。

## 约束

- Flutter + Dart；首版面向 iOS，本地 Xcode 构建和真机调试。
- 最低 iOS 部署版本为 iOS 17.0；真机验收设备为已配对的 iPhone 12 Pro（当前 iOS 17.6.1，用户目标为 17.6），通过 Xcode 部署；首版支持浅色和深色系统外观。
- 离线优先；SQLite 为事实来源，Drift 负责类型安全访问和迁移。
- Riverpod 管理依赖注入和 UI 状态；Cupertino 为主要视觉语言。
- 首版不依赖账号、云端同步或联网 API。

## 版本边界

### v0.1.0

基础工程、导航和 UI 骨架；约 50 个初始词根、300–500 个关联单词；词根学习、单词学习、本地学习状态和最小学习记录。FSRS 仅保留未来兼容字段，不实现自定义算法。

### v0.2.0

接入经过验证的 FSRS 实现；每日复习计划、学习统计、设置和本地备份/恢复；补齐迁移和数据校验。

### v1.0.0

扩充并校验高中词库；完善发音、通知、性能、错误恢复、可访问性和发布流程。

## 完成定义

每个版本都必须有：可重复的数据导入、可迁移数据库、明确的空/错/加载状态、最小单元测试，以及在目标 iOS 设备或模拟器上的人工验收记录。
