# Etyra 功能详细规划

## 规划原则

首版只围绕一个可完成、可验证的核心闭环：发现词根 → 理解构词关系 → 学习关联单词 → 主动回忆 → 保存学习结果。所有功能必须说明服务于哪一步，不能为了“像完整产品”而扩张范围。

## 信息架构

```text
App
├── 学习       # 今日入口、继续学习、开始词根/单词学习
├── 词根       # 词根列表、词根详情、关联单词
├── 单词       # 单词列表、单词详情、例句
└── 设置       # 版本、数据管理；v0.2 扩展备份和偏好
```

底部 Tab 首版建议为“学习 / 词根 / 单词 / 设置”。学习是默认入口；详情页通过返回和关联链接形成可追溯路径，不使用深层菜单隐藏核心内容。

## v0.1 功能分解

### F-01 应用壳

范围：Cupertino App、主题、底部导航、路由、全局错误边界和启动状态。

验收：冷启动可进入默认 Tab；路由返回符合 iOS 习惯；启动失败有可重试提示；不依赖网络。

### F-02 词根浏览

范围：词根列表、搜索/筛选预留、加载/空/错误/重试、词根卡片展示可信度和关联单词数量。

验收：可从列表进入详情；无数据和加载失败不出现空白页；未经验证内容有明确提示。

### F-03 词根详情

范围：词根形式、释义、来源/校验状态、词缀关系、关联单词列表、开始学习入口。

验收：用户能理解词根的含义和边界；来源信息可见；关联单词为空时有解释；开始学习能带入当前词根范围。

### F-04 单词浏览与详情

范围：单词列表、单词详情、词性、释义、构词成分、例句、发音占位。

验收：单词详情能回溯到词根/词缀；例句为空时不破坏布局；发音在未接入时显示为不可用或预留状态，不伪造播放能力。

### F-05 词根学习

范围：词根提示卡、释义/构词解释、关联单词预览、主动回忆、跳过、退出确认、进度。

建议流程：

```text
学习说明 → 词根提示 → 用户回忆 → 显示答案/解释 → 记录结果 → 下一项
```

### F-06 单词学习

范围：单词提示、释义回忆、构词提示、例句辅助、结果反馈、下一项。

首版以“知道/需要再学”这类简单反馈为主；评分枚举可扩展，但不在 v0.1 暴露 FSRS 术语。

### F-07 学习 Session

范围：创建 session、队列、当前位置、答题结果、跳过、退出、完成总结、防重复提交。

验收：重复提交不会重复计数；退出不会删除已记录事件；完成后显示数量、完成数、跳过数和下一步。

### F-08 本地学习状态

范围：保存首次学习、最近学习时间、学习次数、完成状态和最小历史记录；应用重启后恢复。

不包含：FSRS 排程、通知、云同步、复杂趋势图。

### F-09 初始词库导入

范围：约 50 个词根、300–500 个关联单词、词缀、构词关系、例句和来源状态。

要求：稳定 ID、幂等导入、来源字段、校验状态、重复项检测、错误报告；词库更新不得覆盖用户学习状态。

## v0.2 功能

- FSRS 适配和复习队列。
- 每日计划、到期复习和基础统计。
- 学习进度导出/导入（手动文件备份与恢复），包括学习状态、学习 Session/事件及必要的复习记录；不嵌入词库正文。
- 设置项和数据库迁移升级。
- 发音资源、通知权限和通知调度。

### 学习进度备份边界（v0.2）

- 用户通过 iOS 文件选择器/分享面板显式导出或导入；离线可完成，不使用账号、云端或自动同步。
- 备份采用有版本号的机器可读数据包，至少包含格式版本、应用/数据 schema 版本、导出时间、关联内容包 ID/版本、记录数量和完整性校验值。具体容器与序列化格式在 ET-09 设计任务中冻结；格式必须可迁移，不能直接导出 Drift 行或 SQL。
- 导出学习状态、学习/复习历史、Session 及恢复所需设置；词库内容本身由独立词库包管理。若恢复时关联内容不存在，仍保留进度并报告缺失内容，不丢弃记录。
- 首版恢复只提供幂等合并：新记录写入、相同 ID 且内容相同的记录跳过；相同 ID 内容冲突或不支持的格式在写入前拒绝整个文件，不采用静默覆盖或部分导入。替换本机全部进度暂不纳入首版。
- 导入先完整解析和校验，再在事务中应用；任一步失败必须回滚。导入前展示文件来源/日期、记录数、兼容性和冲突摘要；成功后展示结果摘要。
- 导出文件可能包含个人学习历史；导出前明确提示文件去向与本地数据关系。加密/密码保护列为待决项，不能在未定前宣称备份已加密。

### 手动词库导入与更新边界（v1.0）

- 用户可从“设置 → 词库管理”选择本地词库包，查看包名、版本、来源/许可摘要及新增、更新、停用数量后确认导入。
- 词库包与学习进度备份分离；词库包只含内容与来源，不含任何用户进度。它必须有稳定内容 ID、package ID/version、格式版本、兼容版本范围、内容摘要校验值和逐条 SourceRef/许可/校验状态；禁止包含可执行代码。
- 更新必须明确包的更新关系和内容修订规则。稳定 ID 更新只触及内容表，不重置学习状态、学习历史或 FSRS 状态；删除项默认标记停用/退役，不物理删除被学习记录引用的内容。
- 先校验格式、兼容性、ID 唯一性、引用完整性、内容来源/许可和载荷校验，再预览并事务应用；无效或不兼容包整体拒绝并保留原库。重复导入相同 package/version/摘要为幂等；同版本不同摘要作为冲突拒绝。
- 校验值用于发现文件损坏，不代表发布者身份认证。首版不建立在线签名/更新服务；来源和再分发许可仍须人工审核。
- 词条释义、构词关系和词源只能来自可追溯来源；不能为了填满词库而臆造或将未验证内容标为 verified。

## v1.0 功能

- 高中词库扩充与审核流程。
- 发音完整性、离线资源管理和性能优化。
- 完整可访问性审计、崩溃/错误恢复和发布检查。

浅色/深色系统外观、动态字体和 VoiceOver 的基础支持属于 v0.1；v1.0 完成更全面的可访问性审计。

## 跨功能验收

- 断网时核心流程可完成。
- 所有异步页面有明确状态，不出现永久 loading。
- 内容来源和 `unverified` 状态不会被遗漏。
- 数据库重启、重复导入、重复答题和退出恢复行为可测试。
- 学习进度备份与词库更新互不覆盖；两类导入均可预览、校验、幂等处理并原子回滚。
- 每个页面至少有一个成功路径和一个失败/空状态测试设计。
