## ET-01 验收标准

- 新开发者能仅凭文档知道三个对话的边界和启动顺序。
- 工程能在锁定的本地版本上创建、分析和运行测试；本阶段不要求完整产品页面。
- 数据库能从空库迁移到当前版本，内容导入可重复执行且不重置用户状态。
- 前端只消费稳定的 domain/application 接口；后端没有 UI 依赖。
- 词源数据有来源、校验状态和审计记录；未知内容不会被当作确定事实。
- 关键决策写入 `docs/DECISIONS.md`，遗留问题有负责人和下一步。
