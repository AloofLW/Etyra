# Etyra 产品目标

## 一句话目标

Etyra 是一款离线优先的 iOS 英语词汇学习应用，通过词根、词缀和构词关系帮助用户理解单词、建立长期记忆，并形成可持续的学习闭环。

## 用户问题

传统单词学习容易变成孤立的拼写和释义记忆：用户知道某个词，却不理解它与其他词的联系，也难以在遗忘后得到合适的复习安排。Etyra 首先解决“理解词的结构”和“把理解转化为可复习记忆”这两个问题。

## 核心用户

首版面向希望系统扩大英语词汇量、并愿意通过词根词缀理解单词的个人学习者。首版不针对课堂管理、教师布置作业或团队协作场景。

## 核心价值

用户应能完成以下闭环：

```text
理解词根/词缀
    ↓
看到可信的构词关系与关联单词
    ↓
在低干扰学习卡片中主动回忆
    ↓
记录结果并在合适时间再次复习
```

## v0.1 必须解决的问题

- 用户能浏览并理解有来源说明的词根和词缀。
- 用户能看到词根与关联单词、构词成分、例句之间的关系。
- 用户能完成词根学习和单词学习，而不是只浏览内容。
- 用户的学习进度和最小学习记录能离线保存。
- 用户在没有网络、账号或云端服务时仍能完成核心学习流程。

## 暂不解决的问题

- 云端账号、跨设备同步和社交排行。
- v0.1 中的完整 FSRS 调度、通知和复杂统计。
- 自动生成且未经审核的词源、释义、例句或关联关系。
- 试图覆盖所有英语词汇的完整词典功能。
- 教师端、课程编排和多人协作。

## 产品原则

1. **先理解，再记忆**：构词关系是学习入口，单词卡片是巩固手段。
2. **可信优先**：词源和构词关系必须有来源；不确定就明确标记。
3. **低干扰**：一次学习只突出一个主要动作。
4. **离线可靠**：核心内容和学习进度不依赖网络。
5. **渐进增强**：v0.1 先完成学习闭环，v0.2 再加入经过验证的智能复习。

## 初版成功标准（基线）

- 新用户可以从词根列表进入详情，并开始一次完整学习 session。
- 一次 session 可以展示卡片、提交结果、处理跳过/退出，并生成总结。
- 应用重启后，已记录的学习状态仍然存在。
- 初始词库约 50 个词根、300–500 个关联单词，内容均有来源或校验状态。
- 核心流程在离线状态下可运行，异常、空数据和重复提交有明确处理。
- 产品团队能通过测试和人工验收复现上述流程，而不是依赖人工数据库操作。
