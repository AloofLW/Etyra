# 前端 UI 规范

- 以 Cupertino 组件和 iOS 语义为主；颜色、间距、圆角、字体和动效集中在主题/设计令牌中。
- 学习页面优先突出一个动作：看构词提示、回忆单词、查看释义或提交结果；避免同屏堆叠次要信息。
- 支持动态字体、足够对比度、VoiceOver 标签、触控目标和 Reduce Motion。
- 所有页面定义加载、空数据、错误和重试状态；首屏不因可选内容阻塞。
- 文案使用稳定的领域术语：词根、词缀、关联单词、例句、学习中、待复习。
- UI 不展示未经验证的词源结论；`unverified` 只能以谨慎提示呈现。
- 中文界面以清楚、稳健的中等偏粗字重为基线：页面/区块标题使用 semibold 或 bold，正文、按钮和导航标签至少 medium；辅助文字避免过浅灰和过细字重。保留 iOS 系统字体与 Dynamic Type，不使用系统字体不支持的字重。
- 底部导航图标使用语义明确、笔画一致的 Cupertino/SF 风格图标；避免突兀的粗重填充图形和与文字抢焦点的大图标。
